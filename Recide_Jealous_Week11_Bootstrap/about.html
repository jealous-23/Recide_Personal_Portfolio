MY BACKGROUND

Learning one build at a time.

I'm a student in Web and Mobile Application Development (WMAD), exploring how design and programming come together to solve problems. I use coursework and personal projects to practice building websites and applications that are understandable, useful, and accessible.

My current focus is strengthening my foundations in semantic HTML, responsive CSS, Bootstrap, Java, and web application development. I believe that each project is an opportunity to experiment, learn from mistakes, and improve.

My approach

Start with the fundamentals, keep the interface clear, test across screen sizes, and improve through feedback.
